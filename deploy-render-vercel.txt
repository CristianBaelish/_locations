=== Opción A (recomendada): TODO en un solo Render ===

Una URL para mapas + API + WebSocket. Sin Vercel, sin DNS raro a *.onrender.com desde el navegador
(el cliente y el servidor son el mismo host).

1) Render → New → Web Service (o Blueprint si usás render.yaml del repo).
   - Conectá el repo de GitHub.
   - Root Directory: vacío (raíz del repo), NO la carpeta "server" sola.
   - Build Command:  npm ci && npm run build
   - Start Command:  npm start
   - Plan: Free (o de pago si querés evitar cold starts).

2) Variables de entorno (Environment) en Render:
   - VITE_GOOGLE_MAPS_API_KEY = tu clave (necesaria en el BUILD de Vite; Render la inyecta en build).
   - FRONTEND_URL = opcional; si más adelante servís el front desde otro dominio, listalo acá separado por coma.

3) Deploy. La URL será algo como https://TU-SERVICIO.onrender.com
   - Abrí esa URL → tiene que cargar la app.
   - https://TU-SERVICIO.onrender.com/health → tiene que decir ok.

4) Vercel: podés dejar de usarlo para esta app, o redirigir el dominio custom a Render si lo tenés.

Nota: hubo un bug en el servidor: CORS usaba una función que nunca llamaba al callback de "cors",
y las peticiones quedaban colgadas para siempre. Eso ya está corregido en server/src/index.js.
